# Ноутбуки

Здесь лежат сохраненные ноутбуки с основными экспериментами.

## Табличные модели

- `boosting/class_reg_hurdle_xgb_lgbm.ipynb` — CatBoost, XGBoost и LightGBM на табличных срезах.
- `boosting/catboost_classifier_positive_regressor.ipynb` — двухэтапная схема: классификатор покупки и регрессор по пользователям с положительным значением.

## Модели по последовательностям

- `sequence_models/final_simple_gru_prediction.ipynb` — финальное обучение GRU.
- `sequence_models/rnn_gru_lstm_experiments.ipynb` — эксперименты с RNN, GRU и LSTM.

Большие срезы данных и веса моделей в репозитории не хранятся.
