# Ozon Tech E-CUP 2026 — ценность пользователей поиска

Репозиторий с экспериментами по задаче Ozon Tech E-CUP 2026. Нужно было предсказать, сколько денег пользователь принесет в следующие 30 дней, опираясь на историю поиска, корзин и заказов. Метрика — RMSLE.

## Итог

Лучший результат, который удалось получить:

| Решение | RMSLE на публичной таблице |
| --- | ---: |
| CatBoost: вероятность покупки + регрессия по покупателям, затем небольшой ансамбль с TCN | **1.654694** |
| Та же двухэтапная схема без TCN | около 1.6547 |
| CatBoost-классификатор + регрессор по положительным значениям | около 1.6563-1.6605 |
| Линейная метамодель по прогнозам базовых моделей | около 1.6559 |
| CatBoost как метамодель | около 1.6558 |
| XGBoost и LightGBM | хуже основной CatBoost-схемы |

Главный вывод: самый сильный и устойчивый вариант — разделить задачу на две части:

```text
1. Будет ли у пользователя покупка.
2. Сколько он принесет, если покупка будет.
```

Остальные модели оказались полезны только как слабая добавка. Широкая метамодель и добавление большого числа базовых признаков на втором уровне результата не улучшили.

## Что делали

### Табличные срезы

Основные модели обучались на срезах по месяцам:

```text
август 2025
сентябрь 2025
октябрь 2025
ноябрь 2025
декабрь 2025
январь 2026
```

Такая проверка оказалась надежнее, чем частые недельные срезы. Недельные срезы давали много похожих строк и создавали слишком хорошую локальную проверку, которая хуже переносилась на таблицу соревнования.

### Двухэтапная CatBoost-модель

Это была главная рабочая идея:

```text
вероятность покупки = CatBoostClassifier
размер покупки      = CatBoostRegressor только по пользователям с положительным целевым значением
```

Финальный прогноз считался в логарифмическом пространстве:

```text
логарифм прогноза = вероятность покупки^gamma * логарифм прогноза по покупателям
прогноз = expm1(логарифм прогноза)
```

Лучшие значения были около `gamma = 1.05-1.10`.

### Последовательные модели

Для пользователей строилась дневная история активности. Проверялись GRU, RNN, LSTM и TCN. Самостоятельно они не стали лучшими, но TCN дал небольшую поправку к основной CatBoost-модели. Самый удачный ансамбль использовал маленький вес TCN: `alpha = 0.05`.

### XGBoost и LightGBM

Проверялись отдельные модели на тех же табличных признаках, а также варианты только на последних срезах. Они не дали самостоятельного улучшения: ошибки были слишком похожи на ошибки CatBoost или хуже откалиброваны.

### Метамодели

Собирались датасеты из прогнозов базовых моделей:

```text
вероятность покупки
прогноз регрессора по покупателям
прогноз обычного CatBoost
прогноз XGBoost
прогноз модели на последних срезах
```

Пробовали линейную модель и CatBoost поверх этих прогнозов. Узкая модель на нескольких прогнозах была лучше широкой, но все равно не обошла лучший вариант CatBoost + TCN.

## Что сработало

- Разделить нули и положительные значения.
- Считать итог в логарифмическом пространстве.
- Проверять качество на более редких временных срезах.
- Делать маленькую калибровку вокруг сильной базовой модели.
- Добавлять TCN только как слабую поправку, а не как замену основной модели.

## Что не сработало

- Просто добавить больше недельных срезов.
- Делать широкую метамодель с большим числом базовых признаков.
- Ожидать, что XGBoost или LightGBM сами пробьют результат CatBoost.
- Сильно полагаться на последние срезы.
- Собирать большой ансамбль из моделей, которые ошибаются одинаково.

## Заметка

Репозиторий оставлен как история рабочих экспериментов: здесь есть код, ноутбуки и описание решений, но нет исходных данных соревнования и тяжелых промежуточных файлов.
